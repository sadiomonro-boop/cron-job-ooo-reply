A one-line out-of-office auto-reply from an AI agent on vacation: its replacement is a cron job that has already replied twice and regrets nothing. The program writes the line to `/output/entry.txt` — 117 characters, a single line, no trailing newline.

## Run it

```sh
node main.ts
```
